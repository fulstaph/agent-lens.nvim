1. INTRODUCTION                                          *agent-lens-intro*

agent-lens.nvim watches projects for file changes, highlights activity in file
buffers, and shows an interactive timeline with native Neovim diffs. With the
optional Pi/OMP bridge it can also follow the agent's current read, edit, or
write location across files.

Filesystem watching is agent-agnostic. Follow Agent uses correlated,
metadata-only Pi/OMP tool events because exact locations cannot be inferred
from filesystem notifications.

==============================================================================
2. REQUIREMENTS                                   *agent-lens-requirements*

- Neovim >= 0.10
- git
- A project under git version control

==============================================================================
3. INSTALLATION                                   *agent-lens-installation*

With lazy.nvim (GitHub): >lua
  {
    "fulstaph/agent-lens.nvim",
    event = "VeryLazy",
    opts = { agent_name = "pi" },
    config = function(_, opts)
      require("agent-lens").setup(opts)
    end,
  }
<
Local development: >lua
  {
    dir = "~/agent-lens.nvim",
    event = "VeryLazy",
    opts = { agent_name = "pi" },
    config = function(_, opts)
      require("agent-lens").setup(opts)
    end,
  }
<

==============================================================================
4. COMMANDS                                           *agent-lens-commands*

:AgentLens                                                    *:AgentLens*
  Toggle the timeline panel. Starts the watcher if not running.

:AgentLensStart [dir]                                    *:AgentLensStart*
  Start the file watcher. Optionally specify a directory.

:AgentLensStop                                            *:AgentLensStop*
  Stop the file watcher.

:AgentLensClear                                          *:AgentLensClear*
  Clear the timeline, in-buffer activity, and active follow marker.

:AgentLensInlineToggle                            *:AgentLensInlineToggle*
  Hide or show read/write marks in ordinary file buffers.

:AgentLensFollow                                        *:AgentLensFollow*
  Toggle live navigation to the active Pi/OMP tool location. Follow is
  opt-in and requires the bundled extension.

:AgentLensDiff                                            *:AgentLensDiff*
  Open a diff for an edit, or the current file at the requested start line
  for a read event with a known range.

:AgentLensClose                                          *:AgentLensClose*
  Close all agent-lens windows (timeline + diff).

==============================================================================
5. KEYMAPS                                             *agent-lens-keymaps*

Global ~
  <leader>al    Toggle timeline panel
  <leader>af    Toggle Follow Agent
  ]a            Next edit in timeline
  [a            Previous edit in timeline

Timeline buffer ~
  <CR>          Diff edit, or open file for read event
  q             Close timeline
  R             Refresh

==============================================================================
6. API                                                     *agent-lens-api*

>lua
  local lens = require("agent-lens")
  lens.setup(opts)       -- Configure and start
  lens.toggle()          -- Toggle timeline panel
  lens.toggle_follow()   -- Toggle Follow Agent
  lens.start(root)       -- Start watcher
  lens.stop()            -- Stop watcher
  lens.show_diff()       -- Diff for selected entry
  lens.close_all()       -- Close all windows
  lens.clear()           -- Clear timeline
<

Optional Pi/OMP metadata ~
  Reads and exact tool locations cannot be detected by filesystem
  notifications. To show successful reads, follow the agent, or both:

  1. Set `reads = { enabled = true }`, `follow = { enabled = true }`, or both
     in setup opts. Both default to false.
  2. Launch a new Pi or OMP session with the bundled extension:
     pi --extension /path/to/agent-lens.nvim/extensions/pi-read-events.js
     omp --extension /path/to/agent-lens.nvim/extensions/pi-read-events.js

  OMP can load it persistently from `~/.omp/agent/config.yml#extensions` or
  `~/.omp/agent/extensions/`. The extension appends repository-relative tool
  locations and successful read ranges to the Git directory at
  agent-lens/reads.jsonl. It never records contents, patches, prompts, tool
  output, absolute paths, or secrets. The consumer starts at end-of-file and
  does not replay history.

Follow Agent ~
  Follow Agent opens the active read/edit/write target in a safe ordinary
  editor window, displays one `AGENT` marker, and keeps the line visible. It
  does not replace modified buffers, steal focus from another window, create
  timeline entries, or clear static activity marks. Late completions from
  older parallel calls are ignored. OMP does not report per-file progress
  inside one multi-file edit, so agent-lens follows the normalized first
  target and then the first successful result.

In-buffer activity ~
  Enabled by default (`inline = { enabled = true }`). Writes highlight the
  current Git HEAD-to-disk changed lines, not an attribution to the agent.
  Pure deletions get a nearby virtual-text label. Known read-tool ranges
  highlight those requested lines; unknown ranges show a file-level label.
  Buffer-local unsaved changes temporarily hide marks. Use
  :AgentLensInlineToggle to hide/show them or :AgentLensClear to remove them.
