1. INTRODUCTION                                          *agent-lens-intro*

agent-lens.nvim watches your project for file changes made by AI coding
agents (Pi, Claude Code, Codex, etc.), highlights activity in file buffers,
and shows an interactive timeline of edits with native Neovim diffs.

Agent-agnostic: watches the filesystem via libuv and diffs against git HEAD.
Any agent that writes files is tracked automatically.

==============================================================================
2. REQUIREMENTS                                   *agent-lens-requirements*

- Neovim >= 0.10
- git
- A project under git version control

==============================================================================
3. INSTALLATION                                   *agent-lens-installation*

With lazy.nvim (GitHub): >lua
  {
    "fulstaph/agent-lens.nvim",
    event = "VeryLazy",
    opts = { agent_name = "pi" },
    config = function(_, opts)
      require("agent-lens").setup(opts)
    end,
  }
<
Local development: >lua
  {
    dir = "~/agent-lens.nvim",
    event = "VeryLazy",
    opts = { agent_name = "pi" },
    config = function(_, opts)
      require("agent-lens").setup(opts)
    end,
  }
<

==============================================================================
4. COMMANDS                                           *agent-lens-commands*

:AgentLens                                                    *:AgentLens*
  Toggle the timeline panel. Starts the watcher if not running.

:AgentLensStart [dir]                                    *:AgentLensStart*
  Start the file watcher. Optionally specify a directory.

:AgentLensStop                                            *:AgentLensStop*
  Stop the file watcher.

:AgentLensClear                                          *:AgentLensClear*
  Clear the timeline history and in-buffer activity marks.

:AgentLensInlineToggle                            *:AgentLensInlineToggle*
  Hide or show read/write marks in ordinary file buffers.

:AgentLensDiff                                            *:AgentLensDiff*
  Open a diff for an edit, or the current file at the requested start line
  for a read event with a known range.

:AgentLensClose                                          *:AgentLensClose*
  Close all agent-lens windows (timeline + diff).

==============================================================================
5. KEYMAPS                                             *agent-lens-keymaps*

Global ~
  <leader>al    Toggle timeline panel
  ]a            Next edit in timeline
  [a            Previous edit in timeline

Timeline buffer ~
  <CR>          Diff edit, or open file for read event
  q             Close timeline
  R             Refresh

==============================================================================
6. API                                                     *agent-lens-api*

>lua
  local lens = require("agent-lens")
  lens.setup(opts)       -- Configure and start
  lens.toggle()          -- Toggle timeline panel
  lens.start(root)       -- Start watcher
  lens.stop()            -- Stop watcher
  lens.show_diff()       -- Diff for selected entry
  lens.close_all()       -- Close all windows
  lens.clear()           -- Clear timeline
<

Optional read tracking ~
  Reads cannot be detected by filesystem notifications. To show successful
  Pi/OMP `read` tool calls, opt in on BOTH sides:

  1. Set `reads = { enabled = true }` in setup opts (default: false).
  2. Launch a new Pi or OMP session with the bundled extension:
     pi --extension /path/to/agent-lens.nvim/extensions/pi-read-events.js
     omp --extension /path/to/agent-lens.nvim/extensions/pi-read-events.js

  The extension appends relative paths and optional requested line ranges to
  the repository Git directory at agent-lens/reads.jsonl. No file contents
  are recorded. The consumer polls every 250 ms (reads.interval_ms), starting
  at end-of-file without replaying historical events. Other read tools, shell
  reads, and failed reads are outside this feature. See README.md for details.

In-buffer activity ~
  Enabled by default (`inline = { enabled = true }`). Writes highlight the
  current Git HEAD-to-disk changed lines, not an attribution to the agent.
  Pure deletions get a nearby virtual-text label. Known read-tool ranges
  highlight those requested lines; unknown ranges show a file-level label.
  Buffer-local unsaved changes temporarily hide marks. Use
  :AgentLensInlineToggle to hide/show them or :AgentLensClear to remove them.
