Filesystem writes from any process are tracked; they are not agent attribution.

1. SETUP                                                *agent-lens-setup*

Add fulstaph/agent-lens.nvim to your plugin manager and configure:
The current release tag is v0.1.0. Pin the plugin to this tag and install
the matching bridge version below.
>lua
  require('agent-lens').setup({
    agent_name = 'pi',
    reads = { enabled = true },
    follow = { enabled = true },
  })
<
Automatic watching defaults to enabled; reads and Follow default to disabled.
Install the optional dual-host bridge, then restart the Pi/OMP session:
>sh
  omp install 'github:fulstaph/agent-lens.nvim#v0.1.0'
  pi install git:github.com/fulstaph/agent-lens.nvim@v0.1.0
<
For local development use `omp install .` or `pi install .` in the checkout.
One-session fallback:
>sh
  omp --extension /path/to/agent-lens.nvim/extensions/pi-read-events.js
  pi --extension /path/to/agent-lens.nvim/extensions/pi-read-events.js
<

2. FOLLOW                                              *agent-lens-follow*

Control is off/following/paused, separately from latest activity. Follow uses
one safe ordinary window in the current tab and never replaces unsaved text.
Pinned, cursor/scroll-bound, diff, preview and special windows are protected.
When necessary it chooses another safe window or opens a non-entered split.

Generated code appears in an unmodified read-only draft; changed text reveals
with a caret and active-line highlight. Unchanged context stays still. Viewport
movement eases near its edge. Batches catch up within 180 ms; reduced motion is
`follow.animation=false`. Duration clamps to 0-400 ms; large blocks skip reveal.

Manual navigation pauses before queued updates can move the editor. Leaving
the followed window/tab pauses current mode. Insert hands the draft back to
its real source, clamps row/column, preserves unsaved source text, and lets
normal input continue without replaying a key. If source loading fails, keep
the draft read-only, stay paused and retry with :AgentLensResume.
Editing commands such as o, cw, and s also hand back source before changing
text, including while paused; existing unsaved source edits are preserved.

Pause keeps transports running, freezes visible draft/view, and stores one
bounded latest pending snapshot. Resume consumes current state, not a backlog.
After success while paused, explicit resume shows the real source.
Error/cancellation discards speculative content; settled calls ignore late
snapshots. Clear resets pending activity and returns enabled Follow to
following/waiting. Stop disables it.
Closing review never resumes automatically. Ordinary key-navigation pauses
can be disabled with `follow.auto_pause=false`; modal/Insert protections remain.

Window modes ~
  current (default): uses the current-tab safe editor selection.
  split: owns one agent window, right by default, without changing input focus.
  Editing unrelated windows continues normally. Interacting with the agent
  window pauses. Closing/reusing it pauses; only explicit resume/mode actions
  recreate it. Inactive tabs freeze; still-following splits catch up on return.
  Teardown keeps user-repurposed windows and source splits with unsaved edits.
  It removes its own winbar when releasing an edited split. If customized,
  Agent Lens stops replacing that winbar.

In-buffer activity ~
  `inline.enabled=true` highlights current HEAD-to-disk write lines and latest
  successful read ranges. Pure deletions get a nearby label. Unknown reads get
  a file-level label. Marks hide during unsaved local edits. Follow marks are
  separate; use :AgentLensInlineToggle or :AgentLensClear for static marks.

3. TIMELINE                                          *agent-lens-timeline*

Default files view groups retained events by path; events view is a flat feed.
Groups order by latest matching activity and expand to individual read/edit
children. Reads retain their reported range. Incoming activity preserves the
selected event ID/file path and screen position. Trimmed selections choose a
nearby surviving row. Paths truncate using actual display width and UTF-8.

Opening successfully acknowledges the selected event, or all group events
matching the filter. Scrolling/rendering does not. Mark-all-seen acknowledges
the retained feed. Trimming/clear remove obsolete acknowledgement state.
+N/-M totals use the latest retained edit per file, even after a read: these
are retained HEAD-to-disk comparisons, not summed snapshots or agent totals.

Timeline keys ~                                          *agent-lens-keymaps*
  j/k, ]a/[a    Move selection
  Tab           Expand/collapse file group
  CR            Open child; group prefers latest matching edit, else read
  p             Preview edit hunk; read opens its reported range
  f             Cycle all/reads/edits filters
  u             Show only new groups/events
  m             Mark all retained activity seen
  g             Toggle files/events view
  R             Refresh
  q/Esc         Close

Global keys default to <leader>al (timeline), <leader>af (toggle Follow) and
<leader>ar (resume). Empty strings disable global bindings. ]a/[a are local to
the timeline, not global. Runtime filter/view toggles do not rewrite setup opts.

4. REVIEW                                              *agent-lens-review*

Review recomputes current HEAD -> disk from the watched repository, including
when cwd differs. Selected old events do not promise historical patches.
Partial line removal is modified; missing tracked files are deleted; untracked
files are added. Renames use separate old/new paths. Unsafe/symlink paths are
rejected; binary/unchanged comparisons report a message. Repositories without
HEAD need a first commit before review; linked worktrees use their own HEAD.

Hunk preview ~
  :AgentLensPreview or timeline p opens a bounded read-only unified float.
  Without a selected timeline row, it uses the current watched file. Narrow
  layouts wrap and scroll. ]h/[h navigates hunks; R recomputes and clamps the
  current hunk; CR opens the full comparison; q/Esc restores the valid origin.

Full comparison ~
  :AgentLensDiff opens/reuses a separate native diff tab using diff_layout.
  ]h/[h navigates hunks; ]f/[f enumerates current safe tracked/untracked/deleted
  paths in deterministic order. Binary files are skipped with a message.
  When watching a Git subdirectory, paths stay relative to that watched root
  and navigation only includes files inside it.
  Pi/OMP metadata and previews are restricted to that directory and rebased to
  its relative paths. Stop retains the review root even when cwd changes.
  R refreshes; q/Esc closes owned windows and returns to the origin. Navigation
  clamps at ends. Streaming writes never change the user's chosen file/hunk.

Origin restoration is conditional on the same buffer still being displayed.
Original splits, views and unsaved text survive. Changing the watched root clears
retained activity so old paths cannot be compared against a different HEAD. Added/repurposed review windows
remain; modified/reused buffers are never force-deleted. Manual window closure
cleans orphan scratch buffers. The last editor window is never closed.
Current-mode Follow pauses for review. Split Follow may continue in its owning
tab and caches latest activity while that tab is inactive. Close never resumes.

5. STATUS                                              *agent-lens-status*

:AgentLensStatus shows root, watcher, Follow control/reason, latest validated
activity and channel facts. Reading/Drafting/Applying/Settled/Failed describe
observed lifecycle; Waiting does not imply thinking. Paused takes precedence.
Metadata states: disabled/waiting/received/error. Preview states:
disabled/listening/receiving/error. Missing logs/no peers are normal waiting.
Only valid data advances receipt time (Unix seconds). A socket or an old log
cannot prove the host is installed/alive. Restart/recovery clears errors.

lens.status() returns a copied StatusSnapshot without contents:
  watcher  {state, root?}
  follow   {control, window, reason?}
  activity {phase, tool?, path?, line?, call_id?}
  metadata {state, last_valid_at?, error?}
  preview  {state, peers?, last_valid_at?, error?}

User AgentLensStatusChanged coalesces discrete changes; no frame polling/spam.
User statuslines/winbars are preserved. Optional statusline integration:
>lua
  vim.o.statusline = "%{%v:lua.require'agent-lens'.statusline()%}"
<
The reevaluated expression renders escaped percent signs in filenames correctly.
Use :checkhealth agent-lens for dependencies/observable facts, :AgentLensResume
for paused control, and :AgentLensStart to restart transports after errors.

6. COMMANDS                                          *agent-lens-commands*

:AgentLens                                                  *:AgentLens*
  Toggle timeline; starts watching if necessary.
:AgentLensStart [dir]                                       *:AgentLensStart*
  Start/restart watching and requested transports.
:AgentLensStop                                             *:AgentLensStop*
  Stop watcher/transports; disable Follow and release its owned UI.
:AgentLensClear                                            *:AgentLensClear*
  Clear retained events/acknowledgement, marks, selection and pending drafts.
:AgentLensFollow                                           *:AgentLensFollow*
  Toggle Follow enabled/off.
:AgentLensPause                                            *:AgentLensPause*
  Pause while retaining incoming activity.
:AgentLensResume                                           *:AgentLensResume*
  Enable/resume at latest safe target; starts needed sources.
:AgentLensFollowMode [current|split]                        *:AgentLensFollowMode*
  Choose mode; no argument toggles without changing control state.
:AgentLensFilter [all|reads|edits]                           *:AgentLensFilter*
  Choose in-session filter; no argument cycles.
:AgentLensStatus                                           *:AgentLensStatus*
  Open read-only details float; q/Esc closes.
:AgentLensPreview                                          *:AgentLensPreview*
  Preview selected/current hunk, or safely open a read range.
:AgentLensDiff                                             *:AgentLensDiff*
  Open selected/current full comparison, or safely open a read range.
:AgentLensInlineToggle                                     *:AgentLensInlineToggle*
  Toggle persistent source-buffer activity marks.
:AgentLensClose                                            *:AgentLensClose*
  Close timeline, review and status-details windows.

7. CONFIGURATION                                      *agent-lens-config*

Defaults (partial nested opts merge with these):
>lua
  require('agent-lens').setup({
    enabled = true, watch_dir = nil,
    debounce_ms = 150, max_timeline_entries = 200,
    timeline_position = 'right', timeline_width = 42, timeline_height = 15,
    timeline = { view = 'files', filter = 'all' },
    diff_layout = 'vertical', auto_open_diff = false, agent_name = 'agent',
    reads = { enabled = false, interval_ms = 100 },
    inline = { enabled = true },
    follow = {
      enabled = false, preview = true, animation = true, animation_ms = 180,
      auto_pause = true, window = 'current',
      split = { position = 'right', width = 0 },
    },
    keymaps = {
      toggle = '<leader>al', follow = '<leader>af', resume = '<leader>ar',
      next_edit = ']a', prev_edit = '[a', open_diff = '<CR>',
      close = 'q', refresh = 'R',
    },
    highlights = {
      added = 'DiffAdd', removed = 'DiffDelete',
      header = 'Title', timeline_file = 'Directory', timeline_time = 'Comment',
      timeline_selected = 'CursorLine',
      follow = 'CursorLine', follow_label = 'DiagnosticInfo',
      follow_cursor = 'DiagnosticInfo',
    },
    filter = {
      ignore_patterns = {
        '*.swp', '*.swo', '*~', '*.pyc', '__pycache__/**', '.git/**',
        'node_modules/**', '.DS_Store', '*.lock', 'lazy-lock.json',
      },
    },
  })
<
Invalid option types or values are reported once and replaced by defaults.
Git ignore rules also apply to watched files; glob patterns match literally
except `*`, `?` and `[...]`/`[!...]`. Panel position: right/left/bottom. Diff layout: vertical/horizontal. Follow
mode: current/split. Split position: right/left; width 0 means half width,
positive integer widths clamp. Timeline view: files/events; filter:
all/reads/edits. Animation duration: 0-400 ms. Theme-linked groups need no icons
or patched font; status/text labels remain readable without color.

8. LUA API                                               *agent-lens-api*
>lua
  local lens = require('agent-lens')
  lens.setup(opts)
  lens.start(root)             -- boolean; false when directory/watcher unavailable
  lens.stop()
  lens.toggle()
  lens.toggle_follow()          -- boolean enabled (paused is enabled)
  lens.pause_follow()           -- boolean
  lens.resume_follow()          -- boolean; enables and starts needed sources
  lens.set_follow_window(mode)  -- boolean
  lens.preview()                -- boolean success
  lens.show_diff()              -- boolean success
  lens.status()                 -- copied StatusSnapshot
  lens.statusline()             -- escaped compact text
  lens.clear()
  lens.close_all()
<
Re-running setup removes disabled/moved plugin mappings, preserving user
replacements. Empty strings and false disable bindings. Invalid watch_dir values
and ignore lists warn once and fall back to defaults.

Compatibility helpers for integrations remain available in agent-lens.diff
(file_diff, status_summary) and agent-lens.timeline (latest_for_path,
latest_edit_for_path). Timeline entries retain metadata/stats, not diff bodies.

9. BRIDGE AND PRIVACY                                  *agent-lens-bridge*

extensions/pi-read-events.js produces complete metadata-only JSONL in the
active Git directory's agent-lens/reads.jsonl (new files mode 0600). Contents,
patches, prompts, raw deltas, output, absolute paths and secrets never enter it.
Producer and consumer independently validate repository paths, .git exclusion,
symlink components, lifecycle IDs/phases, ranges and edit-only progress sequence.
Metadata polling starts at EOF; historical events are not replayed, so the
bridge truncates the log once it exceeds 4 MiB.

extensions/live-preview.js separately sends code snapshots over private local
Unix sockets (directory 0700/socket 0600, current uid) on macOS/Linux. No draft
contents go to target files, swap, logs or public status. Limits: 1 MiB, 20,000
lines, eight peers, bounded queues/tombstones and one newest pending snapshot.
Snapshots coalesce every 25 ms. Supports full writes, Pi oldText/newText,
numeric OMP hashline PUT/CUT/insert, and apply_patch add/update with unique
context. Ambiguous/unsupported inputs fall back to metadata locations.
Providers that deliver one complete delta can only reveal after receipt.

Source buffers load through normal Neovim readers; modified buffers retain
text. Failed loads report errors and can be retried. Successful completion
uses real source; connection closure consumes already-written metadata first.
Stopping/removing the host bridge stops production. Disable reads/Follow to
stop consumption. The path-only JSONL history remains until deleted.
